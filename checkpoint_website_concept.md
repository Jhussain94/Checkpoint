# CHECKPOINT
### *A digital archive by Camberwell students*

---

# CORE CONCEPT

Checkpoint is an interactive game-style website where students leave behind digital “drops” of themselves for others to discover.

Rather than feeling like a traditional university website or social media platform, the experience should feel like exploring a living digital world.

Users wander through a fictional campus-inspired map and uncover:

- songs
- playlists
- meme clips
- photos
- memories
- anonymous thoughts
- sketches
- unfinished work
- status updates

The emotional idea behind the project is:

> students leave fragments of themselves behind for future students to discover later.

The world slowly grows over time and becomes a shared memory archive.

---

# CORE EXPERIENCE FLOW

Arrival Screen  
→ World Map  
→ Click Checkpoint  
→ Open Drop  
→ Leave Your Own Drop  
→ Return to Map

The experience should feel:

- non-linear
- exploratory
- playful
- emotional
- nostalgic
- social

Users should be encouraged to wander freely instead of following strict navigation paths.

The map acts as the central hub of the experience.

# DROP SYSTEM

## Core Mechanic

Users leave behind “drops.”

A drop should feel like:

> a digital artifact left behind in the world.

Not simply a social media post.

---

# OPENING A DROP

When users click a checkpoint or post:

A popup/modal opens displaying:

- image
- song
- video
- text
- caption
- anonymous username
- mood
- timestamp
- reactions/icons

---

## Example Drop

🎵 Drop Found

“Played this every night during deadline week.”

[ Spotify Embed ]

Mood: exhausted but hopeful

Left by: anonymous student

---

## Coding Notes

- modal popup
- smooth animations
- close button
- optional comments/reactions later
- layered UI transitions

---

# EMOTIONAL TAGGING SYSTEM

Instead of only categories, users can tag drops with emotions.

Examples:

- hopeful
- overwhelmed
- nostalgic
- lonely
- peaceful
- chaotic
- inspired

This allows:

- emotional sorting
- color-coded drops
- mood-based discovery
- more human interaction
